# Demo Script

1. Chay backend bang `npm start` trong thu muc `backend`.
2. Mo `http://localhost:3000`.
3. Kiem tra thanh dieu huong gom Thuc don, Gio hang, Tra cuu don, Dang nhap, Admin.
4. Goi `GET http://localhost:3000/api/health` va xac nhan API tra ve `success: true`.
5. Chay schema `database/schema.sql`.
6. Chay seeder mau `database/seeders/001_seed_sample_data.sql`.
